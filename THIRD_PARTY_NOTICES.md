## Included in the source and the release zip

### ServerPackCreator start scripts (LGPL-2.1-or-later)

`resources/templates/neoforge/start.bat`, `start.ps1` and `install_java.ps1` are
the start scripts generated by [ServerPackCreator](https://github.com/Griefed/ServerPackCreator)
by Griefed, copied unmodified. GodlyPanel copies them into new modded-Minecraft
servers so the server can install its own mod loader and Java.

Each file carries its own copyright and licence header
("Copyright (C) 2025 Griefed", GNU Lesser General Public License, version 2.1 or
later), and the full licence is at
<https://github.com/Griefed/ServerPackCreator/blob/main/LICENSE>. They are
separate files that GodlyPanel does not link against, and they can be replaced
with your own copies.

These scripts in turn download and run
[ServerStarterJar](https://github.com/Griefed/ServerStarterJar) and
[Jabba](https://github.com/Jabba-Team/jabba) at run time.

## Downloaded at run time, not shipped

- **SteamCMD** is downloaded from Valve on request. It is Valve's software and is
  covered by the Steam Subscriber Agreement; GodlyPanel does not redistribute it.
- **Game server files** are downloaded by SteamCMD from Steam. Every game named
  in this project belongs to its respective owner.
- **Game artwork** shown on the dashboard is fetched from Steam's public CDN the
  first time it is needed and cached on your own computer. It is not part of this
  repository or the release zip. You can replace any of it with your own image or
  a plain colour in Settings.
- **Minecraft mods** are downloaded from CurseForge using an API key that you
  supply, under CurseForge's terms.
