## Reference full command lines as sourced
- FP-DL (Windows): `srcds.exe +maxplayers 20 -console +gamemode sandbox +map gm_construct +sv_setsteamaccount <your token>`
- FP-WS (Windows): `srcds.exe +maxplayers 20 -console +host_workshop_collection 157384458 +gamemode zombiesurvival +map zs_cleanoffice_v2`
- FP-DL (Linux): `./srcds_run -game garrysmod +maxplayers 32 +map gm_construct`
- LGSM default: `-game garrysmod -strictportbind -ip ${ip} -port ${port} -tickrate ${tickrate} +host_workshop_collection ${wscollectionid} +clientport ${clientport} +tv_port ${sourcetvport} +gamemode ${gamemode} +map ${defaultmap} +sv_setsteamaccount ${gslt} +servercfgfile ${servercfg} -maxplayers ${maxplayers} -disableluarefresh` with LGSM defaults ip=0.0.0.0 port=27015 clientport=27005 sourcetvport=27020 defaultmap=gm_construct maxplayers=16 tickrate=66 gamemode=sandbox.

Note on the `+` vs `-` forms: `+word value` is a console command/convar executed at start (FP-CLP: "+<ConVar>: Sets ConVar of a console variable after the game is started"; VDC engine section: "+map", "+maxplayers", "+ip", "+hostport", "+clientport", "+hostname"). `-word` is an engine launch option read by the program. All values are a separate token after a space (no `=`).

## Panel recommendation (derived only from the sourced rows above)
Minimum that every source agrees on: `srcds.exe -console -game garrysmod +maxplayers <n> +gamemode <mode> +map <map> +sv_setsteamaccount <token>`; add `-port <port>` (and `-strictportbind` optional), `-ip <addr>` only when binding to one NIC, `-tickrate <n>` only if changed from 66, `+host_workshop_collection <id>` for mods, `-disableluarefresh` (LGSM default), `-condebug` and `-noconclr` for logging.
