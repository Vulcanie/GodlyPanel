## Conflicts between pages (both values kept, not resolved)

1. -aiLimit, negative values. BI (Debug, #Debug): "A value less than or equal to zero simply disables any possible AI." XGamingServer startup-parameters page: "A negative value disables the limit." (XGamingServer's own summary table: "-1 = unlimited".) The two pages describe opposite meanings for zero and negative values.
   - BI: https://community.bistudio.com/wiki/Arma_Reforger:Startup_Parameters#Debug
   - XG: https://xgamingserver.com/docs/arma-reforger/startup-parameters
2. -aiPartialSim. BI: "number value, default: 4", example "-aiPartialSim 5". XGamingServer: described as a flag ("Enables AI partial simulation mode ... Added in v1.2"), example has no value.
   - BI: https://community.bistudio.com/wiki/Arma_Reforger:Startup_Parameters#Debug
   - XG: https://xgamingserver.com/docs/arma-reforger/startup-parameters
3. -addons and -addonsDir separator. BI: comma-separated (example `-addons 88037E46AD234C72,88037E46AD234C73`). XGamingServer: "Space-separated mod names" (example `-addons MyCustomMod AnotherMod`). BI's -addons also names GUIDs as the preferred mod ID; XGamingServer says "mod names".
   - BI: https://community.bistudio.com/wiki/Arma_Reforger:Startup_Parameters#General
   - XG: https://xgamingserver.com/docs/arma-reforger/startup-parameters
4. -bindIP and -bindPort targets. BI: override gameHostBindAddress and gameHostRegisterBindAddress (bindPort: gameHostBindPort and gameHostRegisterBindPort). XGamingServer: override bindAddress and publicAddress (bindPort: bindPort and publicPort). The config key names differ between the two; the BI key names are the BI page's words.
   - BI: https://community.bistudio.com/wiki/Arma_Reforger:Startup_Parameters#Hosting
   - XG: https://xgamingserver.com/docs/arma-reforger/startup-parameters
5. -nwkResolution example. BI: range 100..1000m. XGamingServer example: `-nwkResolution 10` (outside BI's stated range).
   - BI: https://community.bistudio.com/wiki/Arma_Reforger:Startup_Parameters#Network_Tuning
   - XG: https://xgamingserver.com/docs/arma-reforger/startup-parameters
6. -profile value. BI accepts a parent directory name or a path; XGamingServer's text says a path only. Not a hard conflict, noted for the panel.
7. -logLevel default. BI does not state a default; XGamingServer says "normal (default)". Recorded as NOT FOUND in the table.
8. -logStats value. BI: optional interval in milliseconds, no value logs every second (example "-logStats - logs every seconds"). XGamingServer: interval in ms; example -logStats 5000. Consistent; no value default is only on BI.
