# VEIN sources
Server exe: VeinServer-Win64-Test.exe (Windows shipping build, https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup); VeinServer.exe is the launcher and VeinServer-Win64-Test the child process (https://github.com/WindowsGSH/WindowsGSH.VEIN); Linux build VeinServer-Linux-Test (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/)
Server app id: 2131400 (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup, https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/, https://github.com/WindowsGSH/WindowsGSH.VEIN). Game app id 1857950 is from https://xgamingserver.com/blog/setting-up-a-dedicated-server-for-vein/ only.
## BASICS
1. https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup | WIKI | Vein Dedicated Server Setup | Says use app id 2131400; launch example; UDP 7777 game, UDP 7778 query, TCP 7777 optional RCON; no stop instructions ("To be determined").
2. https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/ | COMMUNITY | VEIN Dedicated Server: Setup, Ports and Game.ini | Host guide checked against 0.025; app 2131400; Linux and Windows exe names; UDP 7777 game, UDP 27015 query, changeable with -Port= and -QueryPort=.
3. https://xgamingserver.com/blog/setting-up-a-dedicated-server-for-vein/ | COMMUNITY | How to Install a Vein Dedicated Server: Step-by-Step Tutorial | Warns game 1857950 vs server 2131400; config folder paths; discusses query port 7778 vs 27015; player cap discussion.
4. https://github.com/WindowsGSH/WindowsGSH.VEIN | REPO | WindowsGSH.VEIN (VEIN Dedicated Server) | Management module (not an image); installs with anonymous SteamCMD app 2131400; exe names; game 7777 and query 7778 UDP; marked as needing live testing.
5. https://ramjet.notion.site/Dedicated-Servers-17ef9ec29f1780aa8b6cc84bf31c2634 | OFFICIAL | Dedicated Servers (Ramjet Notion) | NOT RETRIEVED: fetch returned only the word "Notion". Search snippet only: steamcmd +login anonymous +app_update 2131400; older page lists UDP 27015 and 7777.
## CONFIG
1. https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/ | COMMUNITY | VEIN Dedicated Server: Setup, Ports and Game.ini | Game.ini at Vein/Saved/Config/LinuxServer (WindowsServer on Windows); gameplay in Engine.ini [ConsoleVariables]; keys AdminSteamIDs, SuperAdminSteamIDs, WhitelistedPlayers, DiscordChatWebhookURL, DiscordChatAdminWebhookURL, ServerDescription, HTTPPort.
2. https://xgamingserver.com/blog/setting-up-a-dedicated-server-for-vein/ | COMMUNITY | How to Install a Vein Dedicated Server | Game.ini section [/Script/Vein.VeinGameSession] with AdminSteamIDs and SuperAdminSteamIDs (SteamID64); Engine.ini for gameplay overrides; both Windows and Linux paths; multiple-admin syntax disputed.
3. https://www.gameserverkings.com/knowledge-base/vein/vein-console-commands/ | COMMUNITY | VEIN Console Commands: Cheats, Admin Menu and Server Settings | Admin menu Config section; vein.Autosave.Interval (default 300 s); no save or shutdown console command; RCON removed in 0.019 Hotfix 2.
4. https://client.citadelservers.com/knowledgebase/1002/Citadel-Servers---VEIN-Dedicated-Server-Configuration-Guide..html | COMMUNITY | Citadel Servers - VEIN Dedicated Server Configuration Guide | Game.ini and Engine.ini under the server directory (no exact paths); stop the server before editing, restart after. Page is about 153k characters; only the first 100k was read.
5. https://github.com/WindowsGSH/WindowsGSH.VEIN | REPO | WindowsGSH.VEIN (VEIN Dedicated Server) | Vendor-managed settings (game rules, name, password, whitelist, admin lists) in Vein/Saved/Config/WindowsServer/Game.ini.
6. https://hub.docker.com/r/johnnyknighten/vein-server | REPO | johnnyknighten/vein-server - Docker Image | Full environment variable table (VEIN_SERVER_NAME, _PORT 7777, _QUERY_PORT 27015, _MAX_PLAYERS 16, _PASSWORD, _PUBLIC, VAC, backups, cron); CONFIG_FILE_<file>_SECTION_<section>_VAR_<var> pattern; Game.ini in /vein-server/server/Vein/Saved/Config/LinuxServer.

## MODS
