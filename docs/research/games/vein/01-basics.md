# VEIN - BASICS (extracted facts)

Each line is copied from the page named in its URL. Where pages disagree, both values are given.
Raw text copies: `...\research\vein\raw\` (01 wiki mirror, 02 GameServerKings, 03 xgamingserver, 04 WindowsGSH GitHub, 05-08 Ramjet pages). Wiki copy is a r.jina.ai mirror because the wiki returned HTTP 403 to a direct fetch.

- Steam app id: 2131400 (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup ; https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/ ; https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25 ; https://github.com/WindowsGSH/WindowsGSH.VEIN)
- Steam app id, game (not the server): 1857950 (https://xgamingserver.com/blog/setting-up-a-dedicated-server-for-vein/ only; says "do not install the server from the game ID"). Not on the wiki or Ramjet pages.
- Anonymous login works?: Yes. Wiki: "Steam> login anonymous" then "app_update 2131400 validate". GameServerKings: "anonymous SteamCMD login works". Ramjet: "+login anonymous +app_update 2131400 validate +quit" (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup ; https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/ ; https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25 ; https://github.com/WindowsGSH/WindowsGSH.VEIN)
- Install size: "at least 5GB of free disk space"; "The server files consume about 5GB of space (as of December 28th Vein launch)" (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup)
- Server exe name (Windows, shipping build): VeinServer-Win64-Test.exe, in Vein/Binaries/Win64/ (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup ; https://github.com/WindowsGSH/WindowsGSH.VEIN "Shipping process")
- Server exe name (Windows, launcher): VeinServer.exe. Ramjet: "VeinServer.exe will be in (specified directory)" (https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25). GitHub: "Launcher: VeinServer.exe" and "launches the current root VeinServer.exe" (https://github.com/WindowsGSH/WindowsGSH.VEIN). The wiki prerequisites also say "VeinServer.exe is a 64-bit executable" (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup).
- Server exe name (Linux): VeinServer.sh. Ramjet: "VeinServer.sh will be in (specified directory)" (https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25). Also VeinServer-Linux-Test at Vein/Binaries/Linux/ (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). These two Linux names disagree; both are given.
- Which exe stays running: NOT FOUND as a statement. GitHub names VeinServer.exe the "launcher" and VeinServer-Win64-Test.exe the "shipping process" (https://github.com/WindowsGSH/WindowsGSH.VEIN) and does not say which one remains running. See UNSURE list.
- Port, game: UDP 7777 (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup ; https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/ ; https://github.com/WindowsGSH/WindowsGSH.VEIN). Ramjet: "7777 is the port that VEIN sends gameplay packets over" and Config default "Port=7777 ... Defaults to 7777" (https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25 ; https://ramjet.notion.site/Config-279f9ec29f178011a909f8ea9525936d?pvs=25).
- Port, query (Steam): UDP 27015 default. GameServerKings: "UDP 27015 for the Steam query. Change them with -Port= and -QueryPort=" (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). Ramjet: "27015 is used for Steam to check that the server's up" and "GameServerQueryPort=27015" (https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25 ; https://ramjet.notion.site/Config-279f9ec29f178011a909f8ea9525936d?pvs=25).
- Port, query (Steam), conflicting value: UDP 7778, "Query port for Steam's server browser (Always + 2 of game port)" (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup). GitHub: "Steam query 7778 UDP"; "The official current guide describes the query port as game port plus one" (https://github.com/WindowsGSH/WindowsGSH.VEIN). xgamingserver: official wiki says 7778; "Some hosts/community sources report the Steam query port as 27015" (https://xgamingserver.com/blog/setting-up-a-dedicated-server-for-vein/). The wiki's own rule text ("+2") and its table (7778) do not match each other. Wiki also says: "Query Port cannot be between 27020 and 27050 due to Steam using those ports (if you are running locally)."
- Port, TCP (RCON): TCP 7777 "RCON for remote console server access (optional)" (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup). GitHub: "Optional TCP RCON is not exposed because WindowsGSH does not implement it" (https://github.com/WindowsGSH/WindowsGSH.VEIN). No RCON password or command list on the BASICS pages.
- Port, multi-instance example (wiki): instance 2 uses game 7780, query 7781 (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup).
- Port, HTTP (optional): GameServerKings says Ramjet documents "HTTPPort=8080" in Game.ini; server then answers GET /status, /players, /weather as JSON with no authentication (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). Ramjet Config page does not list HTTPPort (https://ramjet.notion.site/Config-279f9ec29f178011a909f8ea9525936d?pvs=25). Unverified against Ramjet directly.
- Minimal start command (wiki, Windows): `VeinServer-Win64-Test.exe -log -port=7777 -MaxPlayers=64`, placed in a .bat in Vein/Binaries/Win64/ (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup). Alternate on the same page: `start vein\Binaries\Win64\VeinServer-Win64-Test.exe -log -port=7777 -QueryPort=7778`. Wiki: other arguments "pending further testing".
- Minimal start command (GameServerKings, Linux build): `VeinServer` with `-log`; the panel sets `-Port` and `-QueryPort` (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). Flags listed there: `-Port=7777`, `-QueryPort=27015`, `-log`, `-multihome=<IP>`, `-onethread`. Its note: "Don't forget the =".
- Minimal start command (Ramjet): NOT FOUND. Ramjet "Starting the Server" section only lists the ports to open (https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25).
- Config files location (Ramjet): "In (install directory)/Vein/Saved/Config/[Windows or Linux]Server, edit or create Game.ini. If that folder/file doesn't exist, create them." Engine.ini: "Create the file if it doesn't exist" (https://ramjet.notion.site/Config-279f9ec29f178011a909f8ea9525936d?pvs=25).
- Config files location (GameServerKings): Vein/Saved/Config/LinuxServer/Game.ini (WindowsServer on Windows); Engine.ini in the same folder (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/).
- Config files location (xgamingserver): Windows ...\VEIN Dedicated Server\Vein\Saved\Config\WindowsServer\ ; Linux .../Vein/Saved/Config/LinuxServer/ (https://xgamingserver.com/blog/setting-up-a-dedicated-server-for-vein/).
- Config files location (GitHub): Vein/Saved/Config/WindowsServer/Game.ini (https://github.com/WindowsGSH/WindowsGSH.VEIN).
- Saves location: below Vein/Saved; "Saves: pinned with -SaveDir to Vein/Saved/SaveGames"; backup target is the whole Vein/Saved (https://github.com/WindowsGSH/WindowsGSH.VEIN). Note the same page: "Import warns when saves may still reside in %LOCALAPPDATA%/Vein following the March 2026 migration."
- Saves location (wiki, Ramjet, GameServerKings, xgamingserver): NOT FOUND. The wiki's "Backing Up Server Data" section says "To be determined" (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup).
- How to stop: NOT FOUND as an official method. Wiki: "Console Commands: To be determined." (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup). GitHub: "No proven save-safe graceful shutdown method is advertised." (https://github.com/WindowsGSH/WindowsGSH.VEIN). Ramjet and GameServerKings give no stop method. xgamingserver says to stop the server before editing config, and "VEIN does not hot-apply config changes" (https://xgamingserver.com/blog/setting-up-a-dedicated-server-for-vein/).
- Query/RCON options: Steam query port (see Port, query above). RCON: see Port, TCP. HTTP query API: see Port, HTTP (optional). GameServerKings: "There's no admin password" (admins by SteamID64 only) (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). RCON commands or password: NOT FOUND.
- RAM/CPU needs: "The server requires at least 8GB of RAM to start. Memory requirements increase as the number of connected players increases." "On Windows Server 2019, the server uses 8GB of RAM without any clients." (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup). CPU: NOT FOUND.
- OS / prerequisites: 64-bit OS "must" be used; DirectX and VC_redist required (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup). Ramjet: "steam_api64.dll" may need copying into VeinServerDirectory/Vein/Binaries/Win64 (https://ramjet.notion.site/Troubleshooting-279f9ec29f17808b82b6d634e66c7f58?pvs=25). Linux: "link steamclient.so ... to ~/(directory)/Vein/Binaries/Linux/steamclient.so" (https://ramjet.notion.site/Initial-Setup-279f9ec29f17809c9ebce81e96ec48e7?pvs=25).
- First-run behaviour: GameServerKings: "Start the server once so it creates its files, then stop it and open Files > Vein/Saved/Config/LinuxServer/Game.ini" (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). The same page says the default file "ships with AdminSteamIDs=1234", a placeholder to replace. Ramjet: "If that folder/file doesn't exist, create them" (https://ramjet.notion.site/Config-279f9ec29f178011a909f8ea9525936d?pvs=25). Ramjet: on Windows, "You may need to run the server with elevated/admin permissions" if it does not show in the server browser (https://ramjet.notion.site/Troubleshooting-279f9ec29f17808b82b6d634e66c7f58?pvs=25). GameServerKings: server is ready when the log shows `SDR RelayNetworkStatus: avail=OK` (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). Ramjet: "Failed to get connection string for heartbeat" "may not be an actual error" if Steam logs on later (https://ramjet.notion.site/Troubleshooting-279f9ec29f17808b82b6d634e66c7f58?pvs=25).
- First-run, config line removal: "Unreal Engine will remove any config lines that are redundant by being the default" (https://ramjet.notion.site/Config-279f9ec29f178011a909f8ea9525936d?pvs=25).
- Anything a panel must not do:
  - Do not edit name, password, max players, query port or bind address in Game.ini by hand on a GameServerKings panel; the panel rewrites them on every start (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/). This is that host's panel, not Ramjet's rule.
  - Do not expose the HTTP API port to the internet; it has no authentication (https://www.gameserverkings.com/knowledge-base/vein/vein-dedicated-server/).
  - WindowsGSH module: server name, password, whitelist and admin lists are "vendor-managed in Vein/Saved/Config/WindowsServer/Game.ini"; RCON "is intentionally not declared or forwarded" (https://github.com/WindowsGSH/WindowsGSH.VEIN). This is the module's own design choice.
  - Do not start the server with `-SaveDir` under a different folder unless you know the save location, since GitHub says saves are pinned there and an import may find saves in %LOCALAPPDATA%/Vein (https://github.com/WindowsGSH/WindowsGSH.VEIN).
  - Wiki: "Your OS must be a 64-bit OS" (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup).
  - Wiki: do not use a query port between 27020 and 27050 if running locally (https://vein.wiki.gg/wiki/Vein_Dedicated_Server_Setup).
