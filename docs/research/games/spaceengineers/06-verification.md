# Space Engineers: real-install verification

Run 2026-10-17 on the scratch panel (127.0.0.1:47999), template `spaceengineers` (registered in both index.js files for the run). Install by the panel's own SteamCMD step (app 298740, anonymous), about 8 GB, 2m45s. Game build: log line `App Version: 01_210_014`, .NET Framework 4.8, `Networking service: Steam`. Server folder `C:\GodlyScratch\data\servers\scratch-spaceengineers`. Nothing outside C:\GodlyScratch was touched. Verdict: **the game CAN be made to start a joinable-looking world from what the panel can write** (one config file, no world copy). Not tested: a real client joining (no game client was used).

## Discrepancies from the dossier, fixed in the template

1. Dossier 01/03 (UNVERIFIED 9): an empty `-path` folder gives **no** default cfg and **no** world; the process idles. Fixed: the panel writes the cfg.
2. Dossier 02: the 2022 source said an unset `OnlineMode` is `PRIVATE`; this build runs `OFFLINE` when unset. The cfg now says `PUBLIC`.
3. Dossier 01: SteamPort 8766 / "second port for Steam": not bound by this build. Dropped from the notes (no clash with Sons of the Forest).
4. Dossier 01: "Torch-less console exits on CTRL_CLOSE and saves": not reachable by the panel (see check 6).
5. Dossier 01: AllowRemoteHttp / Remote API: only attempted with no cfg; the cfg now sets `RemoteApiEnabled false`.
6. Template had no `sessionName` field and wrote an ABOUT note to make `Data`. Now the cfg makes the folder and `fields` is `["sessionName"]`.
7. `-maxPlayers` is no longer written to the start line: the cfg carries the limit (8 by default, 2 to 64 when chosen on the form). The launch form still offers it as an override.

## Not verified

- A real client joining (Steam server list shows the server, `OnlineMode PUBLIC` vs the client's version match).
- `LoadWorld` with a world copied from a client PC; `-ignorelastsession` behaviour; Workshop mods (the `steamclient64.dll` copy was not needed to start; the install root already holds `steamclient64.dll`, `tier0_s64.dll`, `vstdlib_s64.dll` next to `Content`, but `DedicatedServer64` also has copies); the Windows Firewall prompt.
- Ctrl+C/console-closing as a graceful stop (only a person at the window could do it).
