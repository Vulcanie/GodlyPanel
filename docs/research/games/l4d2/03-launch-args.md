# Left 4 Dead 2 dedicated server: launch arguments (srcds.exe)
Status: DRAFT v1 (refining). Date 2026-10-15. Store app 550, dedicated server app 222860 (Tool). Server exe: `srcds.exe` (Windows), game folder passed with `-game left4dead2`.

Facts about the exe and game name
- Dedicated server app 222860 "Left 4 Dead 2 Dedicated Server", anonymous column "Yes" in Valve's server list. Source: https://developer.valvesoftware.com/wiki/Dedicated_Server_Name_Enumeration (table row "Left 4 Dead 2 Dedicated Server 222860 Yes Yes Yes"; the three columns are not labelled in the text I extracted, so what each Yes means is UNVERIFIED, see list).
- `-game` launch name for L4D2 is `left4dead2` (table: launch=left4dead2, update=left4dead2, title Left 4 Dead 2). Source: https://developer.valvesoftware.com/w/index.php?title=Dedicated_Server_Name_Enumeration&action=raw
- Syntax rules: arguments with `-` are command-line parameters; arguments with `+` are console commands/cvars run shortly after autoexec.cfg. Source: https://developer.valvesoftware.com/wiki/Command_line_options ("+<console command> <arg> - Runs command in console shortly after autoexec.cfg is executed").
- Valve's own generic example: `./srcds.exe -game <game> +map <map> +maxplayers X -autoupdate`, and "To start the server, run orangebox\srcds.exe -console -game <vproject>" (older engines). Source: https://developer.valvesoftware.com/wiki/Source_Dedicated_Server

## Minimal recommended command (all pieces sourced above)
`srcds.exe -console -game left4dead2 -ip 0.0.0.0 -port 27015 +maxplayers 4 +map c8m1_apartment` (modcommunity guide https://github.com/modcommunity/how-to-make-a-l4d2-server-with-mods; guide says port-forward UDP and TCP 27015; 4 players default for coop/scavenge, versus up to 8). Add `-strictportbind` (Valve wiki) and `+exec server.cfg` only if wanted. `server.cfg` in `left4dead2\cfg\` runs automatically per a Steam thread; `autoexec.cfg` runs once at start, `server.cfg` each map (modcommunity guide).

## Ports (as sourced)
- 27015 UDP (+TCP for RCON): modcommunity, XGamingServer. Range 27015-27020 per FireDaemon, 27015-27050 per esagames.
- 27020 UDP SourceTV: XGamingServer; Valve wiki "-nohltv ... usually 27020".
- Default client port 27005 (LinuxGSM) and Steam port 26900/26901 (Valve wiki `-steamport`). Panel should treat port + SourceTV as implicit ports; exact offsets UNVERIFIED.

## Notes for the panel
- Valve says `-tickrate` is disabled for L4D2: do not offer it.
- `+` args are cvars run after autoexec.cfg; `-` args are engine switches. Order: Valve examples put `-game` first and `+map` after; nothing says order matters.
- L4D2 server install is anonymous per Valve's server list; app 222860.
