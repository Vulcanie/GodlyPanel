# Left 4 Dead 2 (store 550, dedicated server 222860) - modded servers (researched 2026-10-15)

Facts are for the current public server build as of Oct 2026: SteamCMD public branch build 23990100, last updated 2026-06-30 (source: https://api.steamcmd.net/v1/info/222860). Last two Valve updates: 2026-06-26 "Fixed several crashes and exploits reported via HackerOne", 2026-06-30 "Revised fix for Linux build including latest security patches" (Steam news API, appid 550). No server was installed or run. Web research only. Valve Developer Community (developer.valvesoftware.com) returns 403/bot-check to fetches, so no Valve wiki page could be read; claims that would have come from it are marked UNVERIFIED.

## 1. Verdict

- L4D2 has NO first-party "server downloads your workshop collection" feature that I could confirm. The reliable path is: addon files are `.vpk` files in `left4dead2/addons/`; the server loads them (LinuxGSM docs: the server "loads every `.vpk` in `left4dead2/addons`", https://docs.linuxgsm.com/steamcmd/workshop). Getting the `.vpk` there is done by the admin/panel (manual copy, or a downloader).
- The dominant server mod platform is MetaMod:Source + SourceMod (works on Windows `srcds.exe`; both ship L4D2 Windows binaries, verified by listing the official zips, see section 3).
- Custom campaigns/addons are common but are an awkward fit for a public "friends" server because clients need the same files (section 2.5). SourceMod plugins are server-side only (mostly) and are the safer, more popular choice.

## 2. Workshop addons and custom campaigns

### 2.1 What the server loads, and where
- Addon files are `*.vpk` in `left4dead2/addons/`. Custom-campaign install instructions from a host (updated January 2026): upload `CampaignName.vpk` to `/left4dead2/addons/`, restart, then (if SourceMod is installed) `sm_maps` lists the new maps, and `changelevel <first map name>` switches to it (example `uf1_boulevard`). Source: https://help.freakhosting.com/games/left-4-dead-2/installing-custom-campaigns
- Hosts' "install workshop mods" guides (e.g. GameHostBros, updated 2026-05-25) say: subscribe on Steam, then copy the files from the PC's `left4dead2\addons` folder to the server's `left4dead2/addons` and restart. Source: https://www.gamehostbros.com/guides/games/left-4-dead-2/workshop-mods . Another host says explicitly "L4D2 dedicated servers do not automatically sync with a Workshop collection" and that on the PC the numbered `.vpk` files sit in the `workshop` subfolder of `addons` (number = Workshop id): https://mintservers.com/de/knowledgebase/how-to-install-workshop-mods-l4d2 (seen via search summary; page not opened directly).
- Stop the server before uploading large map files (two hosts advise this: same links; not Valve guidance).
- `left4dead2/addons/workshop/` subfolder is also used by a community downloader (`workshop.py -o /path/to/l4d2/addons/workshop <collection_id>`), thread started 2013 and active to 2019: https://steamcommunity.com/app/550/discussions/0/864959336492894813/ . That the server also loads VPKs from the `workshop` subfolder is implied by that thread; not confirmed first-hand (UNVERIFIED #3).

### 2.2 `+host_workshop_collection` / `host_workshop_map` (CONFLICTING, treat as unconfirmed)
- XGamingServer claims `+host_workshop_collection COLLECTION_ID` in the startup line makes "Workshop content download automatically", and `host_workshop_map MAP_ID` in the console loads a single map: https://xgamingserver.com/docs/left-4-dead-2/workshop-setup (page fetched; it gives only those two lines, no date, no engine evidence). FreakHosting also says to link a collection "in Startup Settings" (no exact parameter named): https://help.freakhosting.com/games/left-4-dead-2/installing-custom-campaigns
- Against it: Steam forum threads (2013, 2014: "is host_workshop_collection supported yet?" with no yes; 2016: "you must do it manually") https://steamcommunity.com/app/550/discussions/0/864959336492894813/ and https://steamcommunity.com/app/550/discussions/0/350540780279067123 ; MintServers says no automatic sync (above); LinuxGSM (Oct 2026) classifies L4D2 as "Downloaded by: LinuxGSM" rather than "game server" (the games whose servers download Workshop themselves are listed separately: CS2, CS:GO, Garry's Mod, DoI, Insurgency, KF2, NS2, Project Zomboid, Unturned, DST, ARK): https://docs.linuxgsm.com/steamcmd/workshop
- Conclusion: do NOT build the panel around `+host_workshop_collection`. It was never confirmed by a first-party source or by a Valve wiki page I could open (UNVERIFIED #1). The panel would need an installed server to test it.

### 2.3 Panel-doable download path (this is how LinuxGSM does it, merged 2026-10-11)
Source: LinuxGSM PR #5018 (merged), https://github.com/GameServerManagers/LinuxGSM/pull/5018 , module https://raw.githubusercontent.com/GameServerManagers/LinuxGSM/develop/lgsm/modules/workshop_core.sh , docs https://docs.linuxgsm.com/steamcmd/workshop .
- Anonymous login is enough for L4D2 Workshop downloads ("Left 4 Dead 2 needs no owned account"; no Steam Web API key needed).
- Collections are expanded to items via the public Steam Web API `ISteamRemoteStorage/GetCollectionDetails/v1` (POST `collectioncount=N`, `publishedfileids[i]=ID`); item details via `GetPublishedFileDetails/v1` (`itemcount`). I called both myself on 2026-10-15 without any key and got valid JSON (collection 2976027012 returned its children; item 3815658696 returned `consumer_app_id: 550`, `filename: "isiw v2026-10-15.vpk"` and a `file_url`). Items that are not public return a non-1 result and are skipped.
- SteamCMD download command used by LinuxGSM: `+force_install_dir <dir> +login <user> <pass> +workshop_download_item <appid-from-API> <itemid> ... +quit`, where appid-from-API is the item's `consumer_app_id`, i.e. 550 for L4D2 items (NOT 222860). Files land in `<dir>/steamapps/workshop/content/550/<itemid>/`.
- L4D2 legacy items arrive as `<hash>_legacy.bin`; this IS the VPK (magic bytes `34 12 aa 55` per the PR) and just needs the name `<itemid>.vpk`. The same finding is in a 2024 Steam thread (rename `_legacy.bin` to `ID.vpk`): https://steamcommunity.com/app/550/discussions/3/7340374598287174069 . LinuxGSM then links it into `left4dead2/addons/<itemid>.vpk` (symlink; on Windows a plain copy is the safer equivalent, UNVERIFIED #4). Addons the admin put in `addons` by hand are left alone by LinuxGSM.
- Keyless alternative that I verified works as a plain HTTP request: `GetPublishedFileDetails` returned a `file_url` (cdn.steamusercontent.com) and a `HEAD` on it gave HTTP 200, Content-Length 56441, matching `file_size`. So a Node implementation could download the `.vpk` directly with no SteamCMD at all. Verified for ONE item only (UNVERIFIED #5: whether every L4D2 item exposes `file_url`, esp. big campaigns).
- Updates: items change on Workshop (`time_updated` in the API); LinuxGSM re-checks on its update command. Clients must have the same version.

### 2.4 Restriction / consistency settings that affect addons
- `sv_consistency` (client files are forced to match server's critical files, default on) and `sv_pure`: a Dec 2024-Jan 2025 Steam thread says consistency 1 kicks players whose files differ (weapon scripts, special-infected .mdl) and that 0 lets others join "without having to download the hosters' addons": https://steamcommunity.com/app/550/discussions/0/598514132636998420 . A 2018 thread: set `sv_pure 0` and `sv_consistency 0`: https://steamcommunity.com/app/550/discussions/0/1736595227862424487/ . Valve's own definition (Pure Servers page) could not be fetched; its search snippet only says `sv_pure` must be set on the command line before VPKs load and `sv_pure -1` disables purity and consistency, and that in L4D2 some VMT effects stop working when sv_pure is 0 or higher: https://developer.valvesoftware.com/wiki/Pure_Servers (snippet only, UNVERIFIED #6).
- `RestrictAddons` block in an `addonconfig.cfg` (keys default/versus/scavenge/mutation15, 0 = no restriction on custom content, 1 = restrict): described in a 2018 Steam post https://steamcommunity.com/app/550/discussions/0/1736595227862424487/ and search results; the file's exact name/location (`left4dead2/cfg/`) and whether it is respected on dedicated servers is UNVERIFIED #7. Do not expose it.

### 2.5 What clients need
- A hosting guide (FreakHosting, Jan 2026): uploading the campaign VPK alone makes joining players get a "Map Missing" disconnect; they recommend a Workshop collection so clients can "download the VPK directly from Steam": https://help.freakhosting.com/games/left-4-dead-2/installing-custom-campaigns . How that works on the client side is not documented there (UNVERIFIED #2).
- Older AlliedModders thread (found via search): clients must install the VPK themselves in their `addons` directory and players were kicked for a missing map (could not open the thread; summary from search result https://forums.alliedmods.net/showthread.php?t=331961 ). A 2014 post says the SourceMod download plugin does not support `.vpk` (search summary only).
- FastDL (`sv_downloadurl`, `sv_allowdownload 1`) exists for L4D2 hosts (https://www.gamehostbros.com/guides/games/left-4-dead-2/fastdl) but whether `addons/*.vpk` is served to clients through it is not confirmed (UNVERIFIED #8). Source's default direct download is throttled (~20 KB/s per a third-party guide).
- Practical rule for friends: tell players to subscribe to the same Workshop items before joining. Custom campaigns on a dedicated server can also cause string-table crashes or stuck loading bars (Steam thread above, Jan 2025, by user Mizu; anecdotal).
- Official/"Best Available" dedicated servers (Valve matchmaking) do not run your addons; a private server is joined by IP/`connect` or Steam group (Steam thread above, Dec 2024).

## 3. MetaMod:Source + SourceMod

### 3.1 Versions (checked 2026-10-15)
- SourceMod stable branch: 1.12.0 build 7255, released 2026-10-02 (GitHub release `1.12.0.7255`): https://www.sourcemod.net/downloads.php?branch=stable ; files `sourcemod-1.12.0-git7255-windows.zip` and `...-linux.tar.gz` at https://github.com/alliedmodders/sourcemod/releases/download/1.12.0.7255/ . Dev branch is 1.13 (build 7478); stay on stable.
- Metamod:Source stable: 1.12.0 build 1227, released 2026-09-25: https://www.sourcemm.net/downloads.php/?branch=stable ; `mmsource-1.12.0-git1227-windows.zip` at https://github.com/alliedmodders/metamod-source/releases/download/1.12.0.1227/ (I downloaded and listed git1226; same layout). SourceMod requires MM:S 1.9.0 or higher, latest recommended: https://wiki.alliedmods.net/Installing_SourceMod
- Metamod "2.0.x" releases on GitHub are the Source 2 branch; not for L4D2.
- The L4D2 Competitive Rework README states it "only supports Sourcemod 1.12 and up": https://github.com/SirPlease/L4D2-Competitive-Rework

### 3.2 Install (verified by listing the real Windows zips, and the wiki)
- Extract the Metamod zip so that `left4dead2/addons/metamod/` and `left4dead2/addons/metamod.vdf` exist. The stable zip contains `addons/metamod/bin/metamod.2.l4d2.dll`, `addons/metamod.vdf`, `addons/metamod_x64.vdf`, `addons/metamod/metaplugins.ini`. `metamod.vdf` content (from the Competitive Rework repo): `"Plugin" { "file" "addons/metamod/bin/server" }`. Metamod wiki: custom VDF/gameinfo.txt edits only needed if it fails to load; L4D1 needs a custom VDF; verify with `meta version` ("Loaded As: Valve Server Plugin."). Source: https://wiki.alliedmods.net/Installing_Metamod:Source
- Extract the SourceMod zip into `left4dead2/` (zip contains `addons/metamod/sourcemod.vdf`, `addons/sourcemod/bin/sourcemod.2.l4d2.dll`, `addons/sourcemod/extensions/sdktools.ext.2.l4d2.dll`, `sdkhooks.ext.2.l4d2.dll`, `addons/sourcemod/configs/admins_simple.ini`, `addons/sourcemod/plugins/*.smx`; the zip has no `cfg` folder). `sourcemod.vdf` content: `"Metamod Plugin" { "alias" "sourcemod" "file" "addons/sourcemod/bin/sourcemod_mm" }`. Wiki: extract the package into the mod folder; remote server: upload `addons`; restart fully; verify in the SERVER console with `meta list` (SourceMod listed) and `sm version`; `Listing 0 plugins` = missing/wrong `sourcemod.vdf`. Source: https://wiki.alliedmods.net/Installing_SourceMod
- Which plugins are on by default: the zip's `plugins/` has admin-flatfile, adminhelp, adminmenu, antiflood, basebans, basechat, basecomm, basecommands, basetriggers, basevotes, clientprefs, funcommands, funvotes, nextmap, playercommands, reservedslots, sounds. `mapchooser`, `nominations`, `randomcycle`, `rockthevote` are in `plugins/disabled/` (a Linux how-to claims mapchooser works out of the box; the zip contradicts it): https://dustbowl.games/knowledgebase/l4d2-sourcemod-metamod
- Admin: edit `left4dead2/addons/sourcemod/configs/admins_simple.ini`, one line per admin: `"<SteamID or !IP or name>" "[immunity:]<flags/@group>" ["password"]`; SteamID form `STEAM_n:o:p` (get yours from the `status` command); example `"STEAM_0:1:16" "bce"`; `"yoursteamid" "99:z"` = root; apply with `sm_reloadadmins` in the server console. Flag `z` = all permissions. Source: https://wiki.alliedmods.net/Adding_Admins_(SourceMod) . Open the admin menu with `sm_admin` in the client console.
- Plugins: `.smx` files in `left4dead2/addons/sourcemod/plugins/`, plugin configs in `left4dead2/cfg/sourcemod/`; load without restart with `sm plugins load <name>` (dustbowl guide above).
- Panel mapping: SourceMod does not need launch arguments; the existing `srcds.exe -game left4dead2 ...` line is enough (LinuxGSM's default line for reference: `-game left4dead2 -strictportbind -ip <ip> -port <port> +clientport 27005 +map <map> +servercfgfile <cfg> -maxplayers 8`, https://raw.githubusercontent.com/GameServerManagers/LinuxGSM/develop/lgsm/config-default/config-lgsm/l4d2server/_default.cfg ).

### 3.3 One-click bundle
- SirPlease's L4D2 Competitive Rework publishes a Windows zip (`L4D2-Competitive-Rework-v1.0.0-windows.zip`, release 2026-05-16, repo updated daily) that is meant to be extracted straight into `left4dead2/` and already contains Metamod, SourceMod, l4dtoolz, Stripper, left4dhooks and many extensions; it ships 9 match modes (Zonemod 2.9.2b, Zonemod Hunters/Retro, NeoMod, NextMod, Promod Elite, Acemod Revamped, Equilibrium, Apex): https://github.com/SirPlease/L4D2-Competitive-Rework . Its separate fresh-install guide is Linux-only ("Windows is not Supported"), but the README says "Linux recommended, Windows is supported": https://github.com/SirPlease/L4D2-Competitive-Rework/blob/master/Dedicated%20Server%20Install%20Guide/README.md . It turns the server into a competitive 4v4 versus server; wrong default for casual co-op, so keep it optional.

### 3.4 Risks / compatibility
- L4D2 server updates can break plugin signatures (an AlliedModders thread, undated, said an update once stripped Linux symbols; SM was fine, gamedata needed fixes): https://forums.alliedmods.net/showthread.php?p=2749801 . lakwsh's l4dtoolz README says tickrate/slot tool "does not rely on signatures" so it survives updates better and warns about crashes with `sv_setmax` above 31 after "The Last Stand" update.
- Updating the server with SteamCMD overwrites nothing in `addons/` that is not part of the base game; the Competitive Rework FAQ says after an L4D2 update run `app_update 222860 validate` (but note, `validate` is their instruction): same guide.
- SourceMod runs on VAC-secured servers; plugins that change `-insecure` are not required. A cheating-prevention note: `-insecure` starts without VAC (Valve wiki search snippet, command line options page; UNVERIFIED #9).

## 4. Popular plugins and categories (counts are GitHub stars, 2026-10-15; popularity ranks are my reading of these)
- Left4DHooks (SilvDev; "Left 4 Downtown and L4D Direct conversion and merger"; 76 stars, pushed 2026-10-11): shared library that many plugins need. It is an ordinary plugin plus gamedata, not an extension: repo contains `sourcemod/plugins/left4dhooks.smx`, `sourcemod/gamedata/left4dhooks.l4d2.txt`, `sourcemod/data/left4dhooks.l4d2.cfg`. Install: copy `sourcemod/` contents into `left4dead2/addons/sourcemod/`. Support thread https://forums.alliedmods.net/showthread.php?t=321696 (not opened). Repo: https://github.com/SilvDev/Left4DHooks
- L4DToolZ (lakwsh fork, release 2.5.1 on 2026-05-31, 192 stars; Metamod plugin): unlocks the player limit and tickrate. Cvars: `sv_setmax <18..32>` (engine default 18; add `+sv_setmax 31` at launch for 31), `sv_maxplayers <-1..31>`, `sv_force_unreserved <0/1>`, `sv_cookie`, `-tickrate <n>` or `sv_tickrate`, `sv_steam_bypass`, `sv_anti_sharing`. Note: "Not removing the lobby limits the maximum number of players to 4 in campaign and 8 in versus". Install: unzip to `addons`; check with `plugin_print` in the server console. Repo: https://github.com/lakwsh/l4dtoolz (README_EN.md). Alternative older fork accelerator74/l4dtoolz (98 stars, cvars `sv_maxplayers`, `sv_force_unreserved`): https://github.com/accelerator74/l4dtoolz
- Extra survivors / more than 4 players: `l4dmultislots` and `l4dinfectedbots` (spawns multiple infected bots, playable infected in co-op, up to 10 vs 10) in fbef0102's collection (313 stars, pushed 2026-10-14): https://github.com/fbef0102/L4D1_2-Plugins . Also named in the Dustbowl guide: l4d2_survivor_extras, l4dinfectedbots.
- Quality of life / admin in the same collection: `l4d_afk_commands` (!afk, !survivors, !infected), `l4d_tanklimit`, `l4d_drop`, `kills`, `l4dffannounce`, `anti-friendly_fire`, `no-rushing`, `l4d2_spawn_props` (admin spawns objects), `l4d_sm_respawn`. Also Mutant Tanks (Psykotikism, 43 stars, pushed 2026-05-16): https://github.com/Psykotikism/Mutant_Tanks
- Competitive: Competitive Rework with ConfoglCompMod, Zonemod etc. (above), 343 stars.
- Stripper:Source (map entity editing, used by competitive configs and map fixes): https://github.com/alliedmodders/stripper-source (77 stars; its Metamod VDF `stripper.vdf` is bundled in Competitive Rework).
- Built-in SourceMod admin plugins (adminmenu, basevotes, basebans, reservedslots, funcommands) cover most hobbyist needs.
- Other Workshop addon categories (not researched with numbers): custom campaigns/maps, survivor/weapon skins, special-infected models, VScript mutations ("Server VScripts / Sourcemod Plugins Collection" exists, https://steamcommunity.com/sharedfiles/filedetails/?id=2976027012 , not opened).

## 5. Recommendation for GodlyPanel
1. Offer a "Workshop addon IDs" list (items or collections) for L4D2: panel resolves collections with the keyless Steam Web API, downloads each `.vpk` (either SteamCMD `+login anonymous +workshop_download_item 550 <id>` or the API `file_url` over HTTP, both observed to work), copies it to `left4dead2\addons\<id>.vpk`, and shows a plain warning that every player must have the same addons or be able to download them. Do NOT rely on `+host_workshop_collection`.
2. Offer a one-click "Install SourceMod + MetaMod" step: download the two stable Windows zips from GitHub releases (or the stable pages), extract into `left4dead2`, tell the user to run `meta list`/`sm version` in the server console, and offer an "admin SteamID" field that writes a `"<steamid>" "99:z"` line to `admins_simple.ini`.
3. Optional extras (separate toggles, not default): L4DToolZ for >8 players, Left4DHooks, Competitive Rework pack.
4. No mod field needed in the start script itself: SourceMod loads through the `addons/*.vdf` files.
5. Keep the default casual: vanilla campaign server; custom content is opt-in with a warning that updates to Workshop items and Valve's server can break compatibility.
