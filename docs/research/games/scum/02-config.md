# SCUM (server app 3792580): config files and every setting

Researched 2026-10-14 for the SCUM dedicated server (Steam tool 3792580, game 513710).

**Builds.** The settings table (ServerSettings.ini, 437 keys) is for SCUM v1.3.4.2.161892, released Oct 8 2026, per https://server-settings.com/en (a GG Host reference; GG Host calls itself "the official SCUM hosting provider" on https://www.gghost.games). The GameServerKings pages (admin, whitelist, economy, loot) were checked by their authors against 1.3.3.4.149664 (Sep 11 2026). SCUM ships roughly monthly and the settings list changes with it, so the file a fresh server generates is the real inventory.

**What this research did NOT do.** No real SCUM server was installed or started (15 GB, anonymous SteamCMD, ~8 GB RAM), so nothing here was read from a file the game itself generated. Every fact comes from the web pages cited. Where sources disagree, both are stated.

## 0. Where the files live and what creates them

Folder, relative to the server install root: `SCUM/Saved/Config/WindowsServer/`. The folder is called WindowsServer on every platform because SCUM only ships a Windows server binary (https://www.gameserverkings.com/knowledge-base/scum/scum-server-settings-ini/).

| file | format | who creates it | restart needed | what it holds | source |
|---|---|---|---|---|---|

Not confirmed against a real file: UNVERIFIED | Yes, read at startup | all gameplay and world settings (437 keys, section 1) | https://www.gameserverkings.com/knowledge-base/scum/scum-server-settings-ini/ |

Other points:
- `-MaxPlayers=<n>` on the command line overrides `scum.MaxPlayers` in the file (https://scum.wiki.gg/wiki/Scum_Dedicated_server_setup and the Gamepires tutorial quoted at https://www.gameserverkings.com/knowledge-base/scum/scum-whitelist-and-admin-access/). `-nobattleye` and `-port=` are launch args, not file settings (same wiki page).
- Value conventions (GameServerKings): in ServerSettings.ini `-1` / `-1.000000` usually means "use the game default", not zero and not off. Durations are `HH:MM:SS`. Prices: `250` = regular money, `2g` = 2 gold. Toggles are `True` / `False`. In EconomyOverride.json a negative timer means "never".
- `PartialWipe`, `GoldWipe`, `FullWipe` reset themselves to False after they run (server-settings.com description), so the server rewrites ServerSettings.ini itself. Whether editing the file while the server runs gets overwritten is UNVERIFIED; stop the server before editing.
- The old per-spawn keys (`MaxAllowedZombiesInWorld`, `MaxAllowedAnimalsInWorld`, `ExteriorPawn...`, etc., documented at https://www.gghost.games/knowledgebase/5/SCUM---Server-Settings-clarification-from-the-developers.html and https://www.g-portal.com/wiki/en/overview-of-input-lines-for-the-scum-serversettings-ini-of-your-scum-server/) are NOT in the current 437-key list and use no `scum.` prefix. They are legacy; do not offer them. GameServerKings says 13 hunt/animal keys (`scum.MaxAllowedAnimals`, `scum.MaxAllowedHunts`, `scum.HuntFailureTime`, `scum.HuntFailureDistance`, `scum.AnimalWorldEncounterSpawnWeightMultiplier`, `scum.NPCWorldEncounterSpawnWeightMultiplier`, six `scum.HuntTriggerChanceOverride_*`, `scum.MasterServerEndpoints`) were removed in the June 2026 update, plus `scum.PuppetLimpingEnabled` / `scum.ArmedNPCLimpingEnabled` (replaced by the `...LimpingHealthThreshold` keys). A form that reads an older file may still see these.
- There is no difficulty / sandbox preset file. Difficulty comes from the individual multipliers below (puppet health, damage, loot, skills, respawn). The server-settings.com page has a "Select preset" control but its preset contents are not in the page HTML: UNVERIFIED.

Path: `SCUM/Saved/Config/WindowsServer/ServerSettings.ini`. Source for every row: server-settings.com anchor (default, range, unit, description wording), plus the extra URLs shown where another page confirms the key. "Label" is mechanically derived from the key name. "Type" is derived from the default value and unit tag in the source. "Allowed values" is the source's range plus unit; the game may accept values outside it but that is not documented (UNVERIFIED). Rows marked `[UNCONFIRMED meaning]` have a source description that itself says it is unknown, unverified, unused or developer-only.
