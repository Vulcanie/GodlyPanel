# SCUM (store 513710, server app 3792580): modded servers (section D)
Researched 2026-10-14. Latest game build seen: 1.3.4.2.161892 (hotfix, 8 Oct 2026; Steam news feed). Loot guide below was checked by its author against 1.3.3.4.149664.

## Verdict
**There is NO supported server mod path.** SCUM has no official mod support, no Steam Workshop, and the developer said on 30 Sep 2026 that mod support will not arrive in 2026. The only "modding" is (a) official-ish server-side data overrides (loot, trader economy, raid times, settings) which are config files, not mods, and (b) unofficial, unsupported `.pak` file drops from Nexus Mods that conflict with anti-cheat.

## What does exist (not real mods)
### Server-side data overrides (config files)
Folder: `SCUM/Saved/Config/WindowsServer/` (the game creates files after the first run; per DoomHosting). Files named by DoomHosting: `ServerSettings.ini`, `EconomyOverride.json` (trader prices/stock; DoomHosting uses `-1` for "game default"), `RaidTimes.json`, `AdminUsers.ini`, `ServerSettingsAdminUsers.ini`, `ExclusiveUsers.ini`, `WhitelistedUsers.ini`, `BannedUsers.ini`, `SilencedUsers.ini`. Name caveat from a search summary (not opened as a primary source): the June 2026 patch notes call the economy file `economy.json`; check the real filename after first run.
Loot customisation (GameServerKings, checked against 1.3.3.4.149664): root `SCUM/Saved/Config/WindowsServer/Loot`; only `Override` folders are read, `Default` folders are exports and edits there do nothing; export defaults with in-game admin commands (`#ExportDefaultLootTree`, `#ExportDefaultItemSpawningParameters`, `#ExportDefaultItemSpawnerPresets`, `#ExportItemSpawnerPresetsInZone <sector>`, `#ExportDefaultItemSpawningCooldownGroups`), copy the wanted files into the matching `Override` folder, edit, then `#ReloadLootCustomizationsAndResetSpawners` (or restart). Preset/item names change between updates. https://www.gameserverkings.com/knowledge-base/scum/scum-loot-configuration/ and https://www.doomhosting.com/help/articles/can-you-mod-scum-server . These belong to the settings catalog (step config), not to a mods feature.
Clients need nothing for these, they are server-only data.

### Unofficial .pak mods (Nexus Mods, https://www.nexusmods.com/games/scum or /scum/mods/<n>)
Nexus returned HTTP 403 to the fetch tool, so everything here comes from a web-search summary of Nexus pages, NOT from pages I opened. Summary: put the mod `.pak` into `SCUM/Content/Paks/~mods` (one page says the same path works "for both local and/or server"); mod pages suggest the launch option `-fileopenlog`, and for servers `-Fileopenlog -nobattleye` in the startup file; some are server-side only, others must be on both server and client; also a standalone client-side mod manager and a Vortex extension (UE4SS Lua mods and cooked .pak content). Mod-page authors warn that the anti-cheat cannot tell mods from cheats and say to remove the folder before joining protected servers. Nexus pages seen only as URLs: /scum/mods/9, 33, 54, 138, 150, 153, 154, 156. None of this is endorsed by the developer, and it can break with any update (SCUM updates roughly monthly with hotfixes).
Risks: running the server with `-nobattleye` removes anti-cheat protection (hosting guide per search summary); clients with mods in their install may be kicked or may need to run without BattlEye. Save compatibility with removed paks: UNVERIFIED.
Popular loaders/categories: no loader in the Unity/BepInEx sense exists officially. UE4SS is mentioned as a Nexus tooling path (UNVERIFIED how well it works on the current build). DoomHosting says the Nexus SCUM tools are mainly "server managers, bots, stats sites, and loot editors", not gameplay mods.

## Recommendation for GodlyPanel
- **Do not offer a "mods" field, workshop id list or loader install step for SCUM.** Set `fields` without `mods`. No supported path exists and the developer said it will not come in 2026.
- Do not auto-add `-nobattleye` or a `~mods` folder. If a user insists, they can drop paks manually; optionally add a short note in the UI/docs: "SCUM has no official mod support (developer, 30 Sep 2026). Loot, economy and raid-time changes are done through config files."
- Put loot/economy/raid-time files (`Loot/Override`, `EconomyOverride.json`, `RaidTimes.json`) into the config catalog work instead. Re-check this step after the next dev update announcing mod scope (SCUM Steam news feed).
