## Answers to the specific questions
- Second start with `StartNewGame true`: with no save on disk it just makes the world again (identical to first start). Behaviour with an existing save is untested (no way to make a save without a game client).
- Saves: no save appeared in `StarRupture\Saved\SaveGames` (folder never created) in any run; the `StarRupture\Saved\SaveGames\<SessionName>\AutoSave0.sav` path stays unverified.
- Launcher vs Shipping: both stay running; the launcher is the parent. `processName` = Shipping exe is correct and its path is under the install folder.
- Panel Stop: reports graceful, ~4-5 s, kills both; log shows `ConsoleCtrl RequestExit` (the game handles Ctrl-Close cleanly) but no save was written (nothing to save here).
- Spaces in the world name: accepted by the game start-up and by the config read; save folder not observable.
